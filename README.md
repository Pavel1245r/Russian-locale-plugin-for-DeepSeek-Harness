# dsh-locale-ru

Русский язык для веб-интерфейса DeepSeek Harness. Плагин регистрирует локаль `ru`
и словари для всех пространств имён клиентских плагинов DSH, поэтому переводится
не только оболочка, но и панели, настройки, диалоги и подсказки инструментов.

## Что делает

- `lib/client.js` (браузерная половина) вызывает `ctx.locale.addLanguage({ id: 'ru', … })`
  и `ctx.locale.register(ns, 'ru', dict)` для каждого пространства имён.
- `lib/index.js` (хостовая половина) намеренно пуст: вся работа происходит в браузере.
- `cordis.patch.yml` вставляет запись `locale-ru` в профиль, когда пакет указан в
  `dsh.profile.bundles`.

После загрузки плагина язык выбирается автоматически, если браузер просит `ru`
(например, `navigator.language === "ru-RU"`), либо вручную:
**Настройки → Общие → Язык → Русский**. Выбор сохраняется в профиле.

## Структура

| Путь | Назначение |
|---|---|
| `locales/en.json` | исходные английские строки по пространствам имён (снимок словарей DSH) |
| `locales/ru.*.json` | переводы: английская строка → русская |
| `locales/ru.overrides.json` | точечные переопределения `пространство:ключ` для слов, которым нужен разный перевод в разных местах (например, `Edit` как «Правка» инструмента и «Изменить» кнопки) |
| `tools/build.mjs` | собирает `lib/client.js` из `locales/*`, подставляет английский для непереведённых ключей и проверяет `{placeholders}` |
| `tools/smoke.mjs` | проверяет, что бандл регистрируется ровно так, как его вызывает загрузчик модулей DSH |
| `locale/*.json` | название и описание плагина для менеджера плагинов |

Сейчас переведены все 63 пространства имён и 2897 ключей, включая общее
пространство `common`, из которого берутся кнопки примитивов. Каталог
`locales/` — источник правды; `lib/client.js` генерируется и вручную не правится.

## Пересборка

```powershell
node tools/build.mjs
node tools/smoke.mjs
```

`build.mjs` печатает число переведённых ключей, список непереведённых строк и
несовпадения подстановок вида `{name}`. Переводы можно дополнять частями:
`locales/ru.01.json`, `ru.02.json`, … — все файлы `ru*.json` объединяются.

## Установка

Из GitHub:

```powershell
dsh plugin --profile <профиль> add github:Pavel1245r/Russian-locale-plugin-for-DeepSeek-Harness
```

Или из локального каталога:

```powershell
dsh plugin --profile <профиль> add file:<путь к этому каталогу>
```

Затем добавьте `dsh-locale-ru` в `dsh.profile.bundles` файла
`<DSH_HOME>/profiles/<профиль>/package.json`. Плагин применяется при следующей
перекомпоновке профиля или после перезапуска приложения. Готовый `lib/client.js`
лежит в репозитории, поэтому сборка при установке не нужна.

## Удаление

Удалите `dsh-locale-ru` из `dsh.profile.bundles`, затем:

```powershell
dsh plugin --profile <профиль> remove dsh-locale-ru
```

## Ограничения

- Реестр локали не поддерживает правила множественного числа и RTL; счётчики
  переведены нейтральными формами («Вызовов инструментов: 3»).
- Текст, зафиксированный в реестрах при регистрации (например, описания слэш-команд),
  обновляется при перерегистрации, а не мгновенно.
- Строки, добавленные в новых версиях DSH, остаются на английском до дополнения словаря.
